How to run a property

1

Fill the subjectAddress, lat/lng, beds, baths, sf, lot, year, condition. Set comp rules.

2

Send the four research promptsCopy each into ChatGPT, Perplexity, Grok and Gemini/Kimi. Paste each JSON reply back.

3

Clean the poolFix condition grades, reject bad comps, resolve fact conflicts. Add MLS CSV rows if you have them.

4

Quant + ClaudeSend the DeepSeek prompt (it now includes the cleaned pool), then run Claude as Chief Appraiser.

5

Price it and log itSet reno and profit, read the verdict, save it. Enter the sale price later.
